# 长期不用的大文件（下载、桌面、文稿、影片）

`scan.py probe bigfiles` 列出这四个目录里单个超过 200MB、修改和访问都在 90 天以前的文件（可用 `--min-mb`、`--min-age-days` 调）。它们是用户自己放的东西，不是哪个程序的缓存：**一律只能写 `decide`，不能 `clean`**；没有副本、删了找不回的标 `preset: "all"`。

## 存储位置

| 目录 | 常见大文件 |
|---|---|
| `~/Downloads` | 软件安装包（.dmg / .pkg / .iso / .xip）、下载的压缩包、视频 |
| `~/Desktop` | 临时拖出来的录屏、导出的视频、压缩包 |
| `~/Documents` | 旧项目的打包、虚拟机磁盘、备份压缩包 |
| `~/Movies` | 录屏、剪辑导出、素材压缩包 |

探针跳过：云盘里只在线的占位文件、受保护路径、隐藏目录、`.app` 与照片图库等包、git 工作树内部（工作树走 git-worktree-build 卡）。

## 怎么判断还在用

| 类型（探针 `kind`） | 判断依据 | 建议档位 |
|---|---|---|
| `installer` 且 `app_installed: true` | 同名应用已经装在“应用程序”里，安装包用过了 | `recommended`（软件官网可重新下载） |
| `installer` 且没装 | 可能是备着的旧版本或还没装，问用户 | `recommended` |
| `archive` 且 `extracted_sibling: true` | 旁边已有解压出来的同名目录，压缩包是重复的 | `recommended` |
| `archive` 没解压 / `video` / `disk-image` / `other` | 可能是唯一一份原件 | `all` |

- 按名称、所在目录说清是什么（如“9 月录的三段屏幕录像”），不要只列文件名。
- 同一目录同一类的合成一张卡；视频和压缩包分开出卡。
- `open_by` 为 `unchecked` 时不代表没被打开；执行时 `act.py` 会逐项复核占用。
- 引用检查：在 `reference_roots` 里被文档提到的文件（例如文章里引用的视频）按普通节点处理，要有 `refs_reviewed`。

## 原生清理与保留设置

没有原生命令，按文件删除（`scope: "files"` 或单文件路径）。不建议用户改任何系统设置；如果下载目录反复堆积安装包，在 `governance` 里提醒“装完软件后顺手删安装包”，不要建议自动清理。

## 不能做的事

- 不能判 `clean`，不能默认勾选。
- 不打开、不解压、不读取文件内容来猜用途。
- 不碰 iCloud 里只在线的文件（删除会同步删掉云端）。
- 照片图库、Final Cut 资源库等包整个跳过，交给软件自己管理。

## 给用户的一句话问题

“下载里这几个装好软件后留下的安装包（共 X GB），官网随时能重新下，删吗？”；“影片里 9 月那三段录屏（共 X GB）没有别的副本，确定不要了吗？”
